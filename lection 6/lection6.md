# Лекция 6: Метод прогонки и Итерационные методы

## Метод прогонки (13.10.26г.)

Метод прогонки (алгоритм Томаса) — это оптимизированная версия метода Гаусса для систем с трёхдиагональными матрицами.

Пусть задана система (1):


$$\begin{cases} d_1 x_1 + b_1 x_2 = r_1 \\ a_i x_{i-1} + d_i x_i + b_i x_{i+1} = r_i \quad (2 \le i \le n-1) \\ a_n x_{n-1} + d_n x_n = r_n \end{cases}$$

Схематически матрица этой системы имеет вид:


$$\begin{bmatrix} X & X & 0 & 0 \\ X & X & X & 0 \\ 0 & X & X & X \\ 0 & 0 & X & X \end{bmatrix}$$


Матрицы такого типа называются **трёхдиагональными**.

### Алгоритм метода прогонки

**I. Прямое исключение (Прямой ход)**


Предположим $d_1 \neq 0$. Разделим первое уравнение на $d_1$:


$$x_1 + \frac{b_1}{d_1} x_2 = \frac{r_1}{d_1} \implies x_1 + \alpha_1 x_2 = \beta_1 \quad \text{где } \alpha_1 = \frac{b_1}{d_1}, \ \beta_1 = \frac{r_1}{d_1}$$

Подставим $x_1$ во второе уравнение: $a_2 x_1 + d_2 x_2 + b_2 x_3 = r_2$

$$(d_2 - \alpha_1 a_2) x_2 + b_2 x_3 = r_2 - \beta_1 a_2$$


Если $d_2 - \alpha_1 a_2 \neq 0$, получаем:


$$x_2 + \alpha_2 x_3 = \beta_2 \quad \text{где } \alpha_2 = \frac{b_2}{d_2 - \alpha_1 a_2}, \ \beta_2 = \frac{r_2 - \beta_1 a_2}{d_2 - \alpha_1 a_2}$$

Аналогично приводим систему (1) к виду (2):


$$\begin{cases} x_1 + \alpha_1 x_2 = \beta_1 \\ x_i + \alpha_i x_{i+1} = \beta_i \\ x_{n-1} + \alpha_{n-1} x_n = \beta_{n-1} \\ x_n = \beta_n \end{cases} \quad (2)$$


Расчетные формулы для прямого хода:


$$\alpha_1 = \frac{b_1}{d_1}, \quad \alpha_i = \frac{b_i}{d_i - \alpha_{i-1} a_i} \quad (i = \overline{2, n-1})$$

$$\beta_1 = \frac{r_1}{d_1}, \quad \beta_i = \frac{r_i - \beta_{i-1} a_i}{d_i - \alpha_{i-1} a_i} \quad (i = \overline{2, n})$$

**II. Обратная подстановка (Обратный ход)**


Из последнего уравнения системы (2) находим $x_n$, а остальные восстанавливаем рекурсивно:


$$x_n = \beta_n$$

$$x_i = \beta_i - \alpha_i x_{i+1} \quad (i = n-1, n-2, \dots, 1)$$

**Количество операций ($A_{ops}$):**

* Прямой ход (вычисление $\alpha_i, \beta_i$): $2 + 6(n-2) + 5 = 6n - 5$ операций.


* Обратный ход (вычисление $x_i$): $2(n-1) = 2n - 2$ операций.
**Итого:** $A_{ops} = 8n - 7$.



> 💡 **Объяснение:** Метод прогонки обладает феноменальной эффективностью. В то время как классический метод Гаусса требует $O(n^3)$ операций, метод прогонки решает систему за $O(n)$ (линейное время). Это достигается за счет игнорирования всех нулей вне трех главных диагоналей.

### Пример: Сведение дифференциального уравнения к СЛАУ

Рассмотрим краевую задачу: $-u''(x) = f(x)$ для $x \in (0,1)$, с условиями $u(0)=u(1)=0$.
Разобьём отрезок $(0,1)$ на равные части с шагом $h = \frac{1}{n+1}$.
Обозначим $v_k \approx u(x_k)$.
Используем конечно-разностную аппроксимацию второй производной:


$$u'(x_k) \approx \frac{u(x_{k+1}) - u(x_k)}{h}$$

$$u''(x_k) \approx \frac{u'(x_{k+1}) - u'(x_k)}{h} \approx \frac{\frac{u(x_{k+1}) - u(x_k)}{h} - \frac{u(x_k) - u(x_{k-1})}{h}}{h} = \frac{u(x_{k-1}) - 2u(x_k) + u(x_{k+1})}{h^2}$$

Получаем систему алгебраических уравнений:


$$\begin{cases} -\frac{v_{k-1} - 2v_k + v_{k+1}}{h^2} = f(x_k) \equiv f_k \quad k = \overline{1,n} \\ v_0 = v_{n+1} = 0 \end{cases} \implies -v_{k-1} + 2v_k - v_{k+1} = h^2 f_k \quad k = \overline{1,n}$$

В матрично-векторной форме это классическая трёхдиагональная система:


$$\begin{bmatrix} 2 & -1 & 0 & \dots & 0 \\ -1 & 2 & -1 & \dots & 0 \\ 0 & -1 & 2 & \ddots & \vdots \\ \vdots & \vdots & \ddots & \ddots & -1 \\ 0 & 0 & \dots & -1 & 2 \end{bmatrix} \begin{bmatrix} v_1 \\ v_2 \\ v_3 \\ \vdots \\ v_n \end{bmatrix} = \begin{bmatrix} h^2 f_1 \\ h^2 f_2 \\ h^2 f_3 \\ \vdots \\ h^2 f_n \end{bmatrix}$$

### Условия корректности (устойчивости) алгоритма

**Теорема:** Пусть коэффициенты системы (1) удовлетворяют условиям:

1. $d_1 \neq 0, d_n \neq 0$

2. $a_i \neq 0, b_i \neq 0 \quad (2 \le i \le n-1)$

3. Диагональное преобладание: $\vert{}d_1\vert{} \ge \vert{}b_1\vert{}$, $\vert{}d_n\vert{} \ge \vert{}a_n\vert{}$ и $\vert{}d_i\vert{} \ge \vert{}a_i\vert{} + \vert{}b_i\vert{} \quad (2 \le i \le n-1)$


Причём хотя бы в одном из условий 3 выполняется строгое неравенство.
Тогда знаменатели в формулах прямого хода не обращаются в нуль ($d_i - \alpha_{i-1} a_i \neq 0 \quad i = \overline{2,n}$), и тем самым алгоритм метода прогонки корректен.

## Итерационные методы решения СЛАУ

Для огромных разреженных матриц прямые методы (Гаусс, LU) становятся неэффективными. Вместо этого применяют итерационные подходы.

Запишем исходную систему $Ax = b \ (1)$ в эквивалентной форме:


$$x = Bx + C \quad (2)$$

Зададим начальное приближение $x^0$ и построим итерационный процесс:


$$x^1 = Bx^0 + C$$

$$x^2 = Bx^1 + C$$

$$...$$

$$x^k = Bx^{k-1} + C \quad (3) \quad k = 1, 2, \dots$$

Основной характеристикой итерационного метода является его сходимость, то есть существование предела $x = \lim_{k \to \infty} x^k$, где $x$ — искомое точное решение (1).

### Критерии сходимости итерационного процесса

**Теорема (Необходимое и достаточное условие):** Итерационный процесс (3) сходится тогда и только тогда, когда спектральный радиус $\rho(B) < 1$, то есть когда все собственные значения матрицы $B$ по модулю строго меньше единицы.

**Доказательство:**
Выразим $x^k$ через начальное приближение $x^0$:
$x^k = Bx^{k-1} + C = B(Bx^{k-2} + C) + C = B^2 x^{k-2} + (B+I)C = B^3 x^{k-3} + (B^2+B+I)C = \dots$

$$x^k = B^k x^0 + (B^{k-1} + \dots + B + I)C = B^k x^0 + \left( \sum_{m=0}^{k-1} B^m \right) C$$

Последовательность $x^k$ имеет предел тогда и только тогда, когда сходится матричный ряд (ряд Неймана) $\sum_{m=0}^\infty B^m$.


$$\lim_{k \to \infty} x^k = \lim_{k \to \infty} (B^k) x^0 + \left( \lim_{k \to \infty} \sum_{m=0}^{k-1} B^m \right) C = \sum_{m=0}^\infty B^m C = (I-B)^{-1}C$$


Необходимым и достаточным условием сходимости матричного ряда $\sum_{m=0}^\infty B^m$ является $\rho(B) < 1$. $\blacksquare$

**Теорема (Достаточное условие):** Если некоторая норма матрицы $B$ меньше единицы ($\vert{}\vert{}B\vert{}\vert{} < 1$), то итерационный процесс (3) сходится.

**Теорема об оценке погрешности:** Если $\vert{}\vert{}B\vert{}\vert{} < 1$, то итерационный процесс сходится, и имеет место оценка:

$$\vert{}\vert{}x - x^k\vert{}\vert{} \le \frac{\vert{}\vert{}B\vert{}\vert{}^k}{1 - \vert{}\vert{}B\vert{}\vert{}} \vert{}\vert{}x^1 - x^0\vert{}\vert{} \quad k = 1, 2, \dots$$

**Доказательство оценки:**
Вычтем $x^k = Bx^{k-1} + C$ из точного решения $x = Bx + C$:
$x - x^k = B(x - x^{k-1})$


Переходя к нормам:
$\vert{}\vert{}x - x^k\vert{}\vert{} \le \vert{}\vert{}B\vert{}\vert{} \cdot \vert{}\vert{}x - x^{k-1}\vert{}\vert{} \quad k = 1, 2, \dots$


Рекурсивно применяя неравенство, получаем:
$\vert{}\vert{}x - x^k\vert{}\vert{} \le \vert{}\vert{}B\vert{}\vert{}^k \vert{}\vert{}x - x^0\vert{}\vert{} \quad (4)$ (отсюда следует сходимость, т.к. $\vert{}\vert{}B\vert{}\vert{} < 1$)

Оценим $\vert{}\vert{}x - x^0\vert{}\vert{}$ через разницу первых двух шагов:
$\vert{}\vert{}x - x^0\vert{}\vert{} \le \vert{}\vert{}x - x^1\vert{}\vert{} + \vert{}\vert{}x^1 - x^0\vert{}\vert{} \le \vert{}\vert{}B\vert{}\vert{} \cdot \vert{}\vert{}x - x^0\vert{}\vert{} + \vert{}\vert{}x^1 - x^0\vert{}\vert{}$


Сгруппируем члены с $\vert{}\vert{}x - x^0\vert{}\vert{}$:
$\vert{}\vert{}x - x^0\vert{}\vert{} (1 - \vert{}\vert{}B\vert{}\vert{}) \le \vert{}\vert{}x^1 - x^0\vert{}\vert{} \implies \vert{}\vert{}x - x^0\vert{}\vert{} \le \frac{1}{1 - \vert{}\vert{}B\vert{}\vert{}} \vert{}\vert{}x^1 - x^0\vert{}\vert{} \quad (5)$


Подставляя (5) в (4), получаем итоговую оценку: $\vert{}\vert{}x - x^k\vert{}\vert{} \le \frac{\vert{}\vert{}B\vert{}\vert{}^k}{1 - \vert{}\vert{}B\vert{}\vert{}} \vert{}\vert{}x^1 - x^0\vert{}\vert{}$. $\blacksquare$

### Метод Якоби (Метод простых итераций)

Имеем $Ax = b \ (1)$, матрица $A = [a_{ij}]_{n \times n}$, причём $\forall a_{ii} \neq 0 \ (i = \overline{1,n})$.
Представим $A$ в виде суммы трех матриц $A = L + D + U$, где:

$$L = \begin{bmatrix} 0 & 0 \\ a_{ij} & 0 \end{bmatrix}, \quad D = \begin{bmatrix} a_{11} & & 0 \\ & \ddots & \\ 0 & & a_{nn} \end{bmatrix}, \quad U = \begin{bmatrix} 0 & a_{ij} \\ 0 & 0 \end{bmatrix}$$

Уравнение (1) запишется как $(L + D + U)x = b$.
Перенесем внедиагональные элементы вправо: $Dx = -(L + U)x + b$.
Умножим слева на $D^{-1}$ (это просто деление каждой строки на диагональный элемент $a_{ii}$):


$$x = -D^{-1}(L + U)x + D^{-1}b \quad (2)$$

Итерационный процесс метода Якоби строится напрямую из (2):


$$x^{k+1} = -D^{-1}(L + U)x^k + D^{-1}b \quad k = 0, 1, 2, \dots$$

Обозначим матрицу перехода $B_J = -D^{-1}(L + U)$ и вектор $C = D^{-1}b$.
Матрица $B_J$ имеет нули на главной диагонали:


$$B_J = \begin{bmatrix} 0 & -\frac{a_{12}}{a_{11}} & \dots & -\frac{a_{1n}}{a_{11}} \\ -\frac{a_{21}}{a_{22}} & 0 & \dots & -\frac{a_{2n}}{a_{22}} \\ \vdots & \vdots & \ddots & \vdots \\ -\frac{a_{n1}}{a_{nn}} & -\frac{a_{n2}}{a_{nn}} & \dots & 0 \end{bmatrix}$$


Тогда метод Якоби записывается в стандартной форме: $x^{k+1} = B_J x^k + C$.

**Теорема:** Для сходимости метода Якоби необходимо и достаточно, чтобы $\rho(B_J) < 1$.
Достаточные условия сходимости (вытекают из требования $\vert{}\vert{}B_J\vert{}\vert{} < 1$ для разных норм):

1. $\max_{1 \le i \le n} \sum_{\substack{j=1 \\ j \neq i}}^n \left\vert{} \frac{a_{ij}}{a_{ii}} \right\vert{} < 1$ ($l_\infty$-норма, строгое преобладание диагонали по строкам)


2. $\max_{1 \le j \le n} \sum_{\substack{i=1 \\ i \neq j}}^n \left\vert{} \frac{a_{ij}}{a_{ii}} \right\vert{} < 1$ ($l_1$-норма, преобладание по столбцам)


3. $\sum_{\substack{i, j = 1 \\ i \neq j}}^n \left\vert{} \frac{a_{ij}}{a_{ii}} \right\vert{}^2 < 1$ (норма Фробениуса).

### Метод Гаусса - Зейделя (15.10.26г.)

Метод Гаусса-Зейделя — это модификация метода Якоби. В методе Якоби покоординатная формула выглядит так:


$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( -\sum_{\substack{j=1 \\ j \neq i}}^n a_{ij} x_j^{(k)} + b_i \right) \quad i = \overline{1,n} \quad (2)$$

На момент вычисления компоненты $x_i^{(k+1)}$, мы уже вычислили новые значения предыдущих компонент: $x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}$. Используя эти самые свежие компоненты в (2) вместо старых значений $k$-ого приближения, мы получаем формулы метода Гаусса-Зейделя:

$$x_i^{(k+1)} = \frac{1}{a_{ii}} \left( -\sum_{j=1}^{i-1} a_{ij} x_j^{(k+1)} - \sum_{j=i+1}^n a_{ij} x_j^{(k)} + b_i \right) \quad i = \overline{1,n}$$

> 💡 **Объяснение:** Логика метода Гаусса-Зейделя проста: "Используй новейшие доступные данные немедленно". Это часто ускоряет сходимость по сравнению с методом Якоби.

**Матричный вид метода Гаусса-Зейделя:**
Разделим сумму на нижнюю ($L$) и верхнюю ($U$) части:
$Dx^{k+1} = -Lx^{k+1} - Ux^k + b$
Перенесем все $x^{k+1}$ в левую часть:
$(D+L)x^{k+1} = -Ux^k + b$

$$x^{k+1} = -(D+L)^{-1} U x^k + (D+L)^{-1} b \quad k = 0, 1, \dots$$


Обозначим матрицу перехода $B_{GS} = -(L+D)^{-1}U$.

**Теорема:** Для сходимости метода Гаусса-Зейделя необходимо и достаточно, чтобы $\rho(B_{GS}) < 1$.
Для нахождения собственных значений матрицы $B_{GS}$ нужно решить уравнение:
$-(L+D)^{-1} Ux = \lambda x \quad (x \neq 0)$
$-Ux = \lambda(L+D)x \implies [\lambda(L+D) + U]x = 0$
То есть собственные значения — это корни характеристического уравнения: $\det[\lambda(L+D) + U] = 0$.

#### Сходимость для положительно определённой матрицы

**Теорема:** Если матрица $A$ положительно определённая ($A = A^T > 0$), то метод Гаусса-Зейделя безусловно сходится.

**Доказательство:**
Пусть $\lambda$ — собственное значение матрицы $-(L+D)^{-1}U$, а $e \neq 0$ — соответствующий собственный вектор:
$-(L+D)^{-1}Ue = \lambda e \implies -Ue = \lambda(L+D)e$.
Умножим обе части скалярно на вектор $e$:
$(-Ue, e) = \lambda((L+D)e, e) = \lambda(Le, e) + \lambda(De, e)$.
Так как матрица симметрична ($A = A^T$), её разложение $A = L+D+U$ означает, что $L = U^T$. По свойству скалярного произведения $(Le, e) = (U^T e, e) = (e, Ue)$.
Тогда уравнение принимает вид:
$(-Ue, e) = \lambda(e, Ue) + \lambda(De, e) \quad (3)$.

Введем обозначения:

1. $(De, e) = \sum_{i=1}^n a_{ii} e_i \bar{e}_i = \sum_{i=1}^n a_{ii} \vert{}e_i\vert{}^2 \equiv \sigma > 0$ (так как диагональные элементы положительно определённой матрицы строго больше нуля).


2. Обозначим комплексное число $(Ue, e) \equiv \gamma = \alpha + i\beta$.


3. Тогда $(-Ue, e) = -\gamma$, а $(e, Ue) = \overline{(Ue, e)} = \bar{\gamma}$.



Подставим эти обозначения в (3):
$-\gamma = \lambda \bar{\gamma} + \lambda \sigma = \lambda(\bar{\gamma} + \sigma)$.
Выразим $\lambda$:


$$\lambda = \frac{-\gamma}{\bar{\gamma} + \sigma}$$


Возьмем модуль от обеих частей:


$$\vert{}\lambda\vert{} = \frac{\vert{}-\gamma\vert{}}{\vert{}\bar{\gamma} + \sigma\vert{}} = \frac{\vert{}\alpha + i\beta\vert{}}{\vert{}\alpha - i\beta + \sigma\vert{}} = \sqrt{\frac{\alpha^2 + \beta^2}{(\alpha + \sigma)^2 + \beta^2}}$$

Для сходимости требуется $\vert{}\lambda\vert{} < 1$, что эквивалентно неравенству под корнем:
$\alpha^2 + \beta^2 < (\alpha + \sigma)^2 + \beta^2$


Раскроем скобки:
$\alpha^2 + \beta^2 < \alpha^2 + 2\alpha\sigma + \sigma^2 + \beta^2$


$0 < 2\alpha\sigma + \sigma^2 \implies \sigma(2\alpha + \sigma) > 0$


Так как $\sigma > 0$, достаточно доказать, что $2\alpha + \sigma > 0$.

Используем исходное условие положительной определённости $A > 0$:
$(Ae, e) > 0$.
$(Ae, e) = ((U^T + D + U)e, e) = (U^T e, e) + (De, e) + (Ue, e) > 0$
$(e, Ue) + (De, e) + (Ue, e) > 0$
Подставляем наши обозначения ($\bar{\gamma}, \sigma, \gamma$):
$\bar{\gamma} + \sigma + \gamma > 0$
$(\alpha - i\beta) + \sigma + (\alpha + i\beta) > 0$
$2\alpha + \sigma > 0$.
Мы получили тождественное истинное неравенство, а значит $\vert{}\lambda\vert{} < 1$, и метод сходится. $\blacksquare$
